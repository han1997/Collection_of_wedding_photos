# 此刻，留念 · 婚礼照片收集

一场婚礼，一个网站。宾客扫码或打开链接上传照片、视频，原文件直接保存到你的 NAS。手机、平板、电脑使用同一套 Web 页面，不再需要微信小程序、AppID 或 AppSecret。

- **一容器一场婚礼**：另一场用另一容器与独立数据目录。
- **不需要注册**：服务端生成匿名会话，同一浏览器再次扫码可找回自己的记录。
- **私有相册**：宾客只看自己的上传，主办者通过 `/admin` 查看全部。
- **原文件保存**：按宾客固定子文件夹和日期归档。改昵称不移动目录，同名宾客不合并。
- **大文件分片**：批量选择、电脑拖放、进度、暂停、重试、重新选择原文件续传；SHA-256 校验防止错文件续传。
- **单容器**：Fastify + node:sqlite，同源提供 HTML、ESM、CSS、API。无需前端构建服务器或云存储。

## 开始使用

需要 Node.js 24。ffmpeg/ffprobe 用于视频元数据和封面，缺少时降级显示，不影响保存原文件。

```bash
npm install
cp .env.example .env
# 编辑 .env，生成两个不同随机密钥并设置管理员密码
openssl rand -base64 48
openssl rand -base64 48
npm run dev
```

打开 `http://127.0.0.1:3000/` 上传；管理入口 `http://127.0.0.1:3000/admin`。
首次管理员登录强制修改密码，再设置婚礼信息、保存二维码。
生产环境 `PUBLIC_BASE_URL` 必须为 HTTPS 地址。

## 浏览器记忆的边界

匿名会话凭证存于 localStorage，默认有效期 180 天，服务端只保存摘要。**昵称不是身份凭据**，不能通过填写别人的名字查看其文件。

- 相同域名、同一浏览器重新进入，可恢复已上传记录。
- 清除网站数据、换浏览器、换设备或隐私浏览可能无法找回。微信内置浏览器与系统浏览器通常也不共享存储。
- localStorage 被禁用时仍能临时上传，页面会提示关闭后可能无法找回。
- 页面关闭后不保证继续上传。未完成任务再次进入可重新选择原文件续传，临时分片默认保留 24 小时。
- 网络错误不会清掉凭证；失效凭证需要用户明确建立新会话。原文件仍由主办者保管。
- 文件签名链接是短期访问凭据，不能公开转发。不要在共享浏览器上保存私人会话。

## 数据目录

```text
/data/
├─ db/                   数据库与备份
├─ guests/
│  └─ <固定随机目录ID>/
│     ├─ guest.json       称呼与目录标识
│     └─ YYYY-MM-DD/
│        ├─ originals/   原文件
│        ├─ thumbs/      缩略图
│        ├─ previews/    预览图
│        └─ posters/     视频封面
├─ events/               旧素材与兼容的婚礼信息
└─ tmp/                  上传分片与回收文件
```

不要手工移动或改名原文件。要整理时先复制一份。备份整个数据目录，包括数据库，不能只备份照片。

## 管理

`/admin` 提供婚礼设置、暂停上传、二维码下载、按宾客/类型筛选、图片/视频查看、原文件下载、删除与限制宾客访问。没有多场活动列表。批量素材可直接从 NAS 文件管理器取出，本版本不提供 ZIP 打包。

HEIC/HEVC 等格式是否可预览取决于浏览器与服务器解码能力。原文件始终保留；默认不转码视频，不调用第三方内容审核接口。主办者需自行审核不合适的内容。

## 升级旧版

先备份旧数据目录。`001_init.sql` 保持不变，新增迁移保留旧宾客 ID、文件路径和关联，不自动搬动或清空照片。
旧库只有一场婚礼时自动沿用；有多场时必须通过 `EVENT_ID` 选择，其他数据仍保留。旧微信身份不会自动绑定到新的浏览器身份，历史素材可由管理员查看。

## 测试

```bash
npm test
npx playwright install chromium
npm run test:web
```

浏览器测试使用独立临时数据库，覆盖上传、恢复、匿名隔离、禁用存储、断网续传、管理设置和多尺寸深浅色布局，截图位于 `test-results/`。
