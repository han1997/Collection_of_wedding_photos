# 现场使用手册

## 婚礼前

1. 在浏览器打开网站 `/admin`，登录并修改初始密码。
2. 填写婚礼标题、新人称呼、日期、地点和欢迎语，开启上传。
3. 下载二维码，打印在桌牌或迎宾区域，旁边附上网站链接。
4. 用另一部手机扫码，上传一张照片和一段视频，确认原文件在 NAS 的 `guests/` 下。
5. 关闭页面，再用同一浏览器扫码，检查“我的上传”能恢复。
6. 用另一浏览器确认看不到刚才的文件。管理页面则能看到全部。

## 婚礼当天

可这样引导：“欢迎扫码，把今天拍到的照片留给我们。只有你和主办者能看到你的上传。”

- 大视频上传时保持页面打开，不要锁屏或切换应用。
- 短暂断网会重试，失败后点击重试；退出页面后需要重新选择原文件才能继续剩余分片。
- 只要同一浏览器的本地数据还在，已上传记录会自动恢复。
- 不要清除网站数据，也不要为了找回记录让宾客填写他人的昵称。
- 微信内置浏览器和 Safari/Chrome 是不同的存储空间，尽量始终用最初上传的浏览器。

## 收集结束

在管理页面取消“允许宾客上传”，保存。已上传记录仍可浏览。
按宾客筛选照片，或直接通过 NAS 文件管理器取走原文件：

```text
guests/<固定目录ID>/guest.json
guests/<固定目录ID>/<上传日期>/originals/
```

管理页面显示目录 ID 与称呼对应关系。同名宾客有不同目录，改称呼不会移动文件。
旧版上传仍可能位于 `events/`，不要删除该目录。

## 常见情况

- **图片无法显示但提示已完成**：缩略图可能还在生成或格式不支持，点击下载原文件。
- **视频无法播放**：浏览器不支持对应编码，下载后用本地播放器打开；NAS 默认不转码。
- **找不到上次记录**：确认域名、浏览器和设备一致，未清数据。无法确认旧身份时由主办者帮助取回素材，不通过昵称直接恢复权限。
- **传错照片**：点击作品后删除并确认；主办者也可删除。
- **临时会话提示**：浏览器拒绝本地存储，本次能上传，但关闭后可能无法找回。

不要手工改名或移动正在使用的数据文件。需要整理时复制一份，备份时保留完整数据目录与数据库。
